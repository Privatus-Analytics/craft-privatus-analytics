# Release Notes for Privatus Analytics

## 1.0.0 - 2026-10-20

### Added
- Initial release.
- Adds the Privatus Analytics tracking script to front-end pages once a site id is set.
- Settings for the script host, single-page app mode, modules, allowed domains, excluded paths, path masks, extra query parameters, canonical URLs and hash routing.
- Leaves out control panel users and chosen user groups.
- Site id and script host accept environment variables.
